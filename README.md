# 둘 · 동네친구, 데이트, 새로운 시작

취향이 가까운 사람을 찾아주는 매칭 웹앱이에요.
추천 상대와 함께 **왜 그 사람을 골랐는지(매칭 로직)**를 화면에서 보여주는 것이 목표예요.

## 주요 기능

- **회원가입·로그인**: Firebase 인증(아이디 + 비밀번호), 만 19세 이상, 프로필 사진 등록
- **오늘의 추천 3명**: 거르기 → 점수 → 양방향 합치기 순서로 계산, 추천 이유를 문장으로 보여줌
- **자동 매칭**: 서로의 추천 상위 3명 안에 있고 서로가 1순위면 바로 연결
- **좋아요·넘기기**: 서로 좋아요를 누르면 매칭
- **채팅**: 매칭된 사람과 메시지·사진 주고받기
- **마음 표현**: 만나기 전(좋아요 / 관심 있어요 / 만나보고 싶어요), 만난 뒤(한 번 더 만나볼래요 / 즐거웠어요 / 인연이 아닌 것 같아요)
- **관심사 검색**: "주말엔 산 타요"처럼 문장으로 검색, 검색 공개에 동의한 사람만 노출, 취향 지도로 거리 표시
- **개발자 화면**: 스위치를 켜면 항목별 점수 계산서와 좌표 비교가 보임

## 매칭 로직

| 단계 | 내용 |
|---|---|
| 1. 거르기 | R1 프로필 완성 · R2 성별 · R3 나이 · R4 거리(중요도 3이면 탈락, 1·2면 감점) · R5 만남 목적 · R6 절대 조건 · R7 관심사 태그 (양방향) |
| 2. 점수 | 항목별 유사도(0~1) × 가중치, 합계 100점. 관심사 20 · 결혼관 15 · 연락 15 · 거리 10 · 외모 10 · 활동 시간 6 · 주말 6 · 음주 6 · 소비 6 · 반려동물 6 |
| 3. 양방향 | 최종 = √(내가 본 상대 × 상대가 본 나). 내 가중치는 내 쪽 점수에만 쓰임 |
| 4. 자동 매칭 | 서로의 상위 3명 안에서 서로 1순위인 쌍을 연결, 남은 사람끼리 반복 |

**관심사 점수** = 0.6 × 태그 겹침 + 0.4 × 취향 좌표 가까움

- 태그 겹침: 같은 태그 1.0 / 관련 태그(등산≈캠핑) 0.5 / 같은 분류(야구↔축구) 0.25, 드문 태그일수록 가중(희귀도), 중요도 ★ ×0.6 · ★★ ×1.0 · ★★★ ×1.6, 겹칠수록 추가 점수는 줄어듦(1 − 0.5^k)
- 취향 좌표: 관심사마다 8개 축(활동성, 야외, 사교, 문화·감성, 미식, 집콕, 몰입·창작, 새로움) 좌표를 두고 코사인 유사도로 비교. 검색도 같은 좌표로 가까운 사람을 찾음

## 폴더 구성

```
dul/
├── public/index.html      배포되는 앱 (src에서 만들어짐)
├── firebase.json          Firebase Hosting 설정
├── firestore.rules        Firestore 보안 규칙
├── deploy.sh / deploy.bat 기존 데이터를 지우고 새로 배포
├── docs/DEPLOY.md         배포 방법 자세히
└── src/
    ├── matching.py        매칭 로직 원본 (Python)
    ├── app_engine.js      같은 로직의 앱용 버전 (JavaScript)
    ├── app_template.html  앱 화면
    ├── gen_profiles.py    가상 회원 480명 생성
    ├── profiles.json      처음 만든 가상 회원 20명
    ├── profiles_500.json  가상 회원 500명
    ├── build_app.py       데이터 + 엔진 + 화면 → 앱 한 파일로
    └── build_deploy.py    배포용 public/ 만들기
```

## 고치고 다시 만들기

```bash
cd src
python3 matching.py               # 처음 20명으로 매칭 결과 확인
python3 gen_profiles.py           # 가상 회원 500명 다시 만들기 (결과는 항상 같음)
python3 build_deploy.py ..        # public/index.html 다시 만들기
```

## 배포

[docs/DEPLOY.md](docs/DEPLOY.md)를 보세요. 요약하면 Firebase 프로젝트를 만들고 이메일/비밀번호·익명 로그인과 Firestore를 켠 뒤, 이 폴더에서 `firebase use --add` → `./deploy.sh`(Windows는 `deploy.bat`).
